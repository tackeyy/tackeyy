### 瀧田 雄介（Yusuke Takita）

**[株式会社Wedge AI](https://wedgeai.co.jp/) 代表取締役** — エンジニア出身の経営者。AIネイティブな会社をつくっています。

AIエージェントが実際にバックオフィスと顧客向けの仕事を担う会社を経営しながら、AIの成果物を顧客に出せる品質へ引き上げるツールをオープンソースで公開しています。

#### 主なプロジェクト

| プロジェクト | 内容 |
|---|---|
| [design-system](https://github.com/wedgeai-inc/design-system) | AIで作った日本語のスライド・白書・図・文書・表を、顧客に出せる品質に仕上げる生成器とチェック機能。ブランドを差し替えられ、文字が枠に収まらなければ生成を止め、AIの癖のある言い回しを指摘します。MIT。 |
| [mission](https://github.com/tackeyy/mission) | Claude Code・Codex向けの自律ループ。計画・実行・レビュー・採点・改善を、採点が基準を超えるまで繰り返します。 |
| [freee-cli](https://github.com/wedgeai-inc/freee-cli) | freee会計の公開APIを使う非公式CLI。請求書・見積書・取引先・経費申請を扱います。 |
| [freee-mcp](https://github.com/freee/freee-mcp) | freee公式のMCPサーバー（コントリビューター）。 |
